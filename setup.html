GPT 截图助手 · WINDOWS

一键隐藏，截下后面的画面。

首次安装本机助手后，“隐藏本页后截图”会自动完成截屏，直接进入框选，无需选择屏幕。

  1. 下载并解压最新的完整插件包。
  2. 打开其中的 windows 文件夹，双击 install.cmd，看到“Installed successfully”后关闭安装窗口。不需要管理员权限。
  3. 点击下方“检查连接”，成功后回到 ChatGPT 刷新页面，即可使用。

从 1.0 升级时，请先在 Edge 扩展页移除旧版，再加载新版。新版使用固定扩展 ID；保留 manifest.json 中的 key 字段。

默认截取原 Edge 窗口所在的显示器；窗口跨屏时取它占面积最大的屏幕。确认或取消后恢复原窗口。截图不写入图片文件，只在内存中传给插件；点击确认后通过 ChatGPT 的正常附件流程上传。

助手仅在使用时由 Edge 启动，不常驻后台。卸载助手可运行 windows/uninstall.cmd。
